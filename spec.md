I have designed a thermal camera PCB which uses a RP2040, a USB connector and a Flir Lepton 3.5. 
I have designed this board because I want a thermal camera that is plug and play, without requiring specialised drivers, with the thermal image being sent over webUSB (using a webapp to display the data) or simply using USB UVC. I want to write an embedded rust firmware for it. I want to use the latest Rust standard that is stable and embassy. If the embassy USB drivers do not have what we need, I want to fork and add the functionality there if it's not too complicated, otherwise we could simply write our own USB stack. I see there is already a lepton_rs driver, but if it doesn't work, we can write our own. I want to also mock the lepton to be able to test this easily and ensure everything works. I also want to have scripts that lint and format the code. I also want to use heapless, so no heap at all. I also want to be able to use the USB port for serial communication for debugging if it doesn't slow down the thermal video too much, otherwise we can debug over the SWD protocol. I also want to use an embedded low footprint logging library for debugging (defmt), in parallel with classical step by step debugging. Let's make a plan, ask any questions.
